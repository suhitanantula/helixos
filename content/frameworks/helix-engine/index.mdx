# Helix Engine v6

**The question isn't which AI to use. It's how to think with it.**

Helix Engine v6 is a cognitive methodology for structuring strategic analysis. Not software — a protocol that Claude reads and enacts. The engine's "code" is written in natural language.

## Triadic Architecture

Three agents grounded in cognitive neuroscience:

| Agent | Symbol | Mode | Function |
|-------|--------|------|----------|
| SENSING | 〰 | Vibes | Weak signals, emergence, sensemaking |
| ARCHITECT | ▲ | Lines | Structural analysis, frameworks, decomposition |
| EVOLVE | ● | Loops | Innovation, iteration, breakthrough |

Grounded in: Aboitiz 2018 (triadic cognition), Peirce semiotics, brain network mapping.

## 8-Dimensional Challenge Fingerprinting

Every challenge is scored 0.0–1.0 across eight dimensions:

1. Complexity
2. Uncertainty
3. Time Pressure
4. Stakeholder Density
5. Data Availability
6. Innovation Requirement
7. Risk Tolerance
8. Scope Breadth

Output: a tempo recommendation and agent pattern. High uncertainty + high innovation requirement → EVOLVE-led. High complexity + low time pressure → ARCHITECT-led.

## Human Pause Points

After each agent completes, a structured pause for human input:

1. **Validation** — does this match your read?
2. **Signal injection** — what do you know that I don't?
3. **Direction** — where should the next agent focus?

This is co-intelligence in practice: AI structures, humans steer.

## Glass-Box Transparency

Every reasoning step is logged in real time — not post-hoc. Seven reasoning step types. Embedded citations. LLV checks throughout. Confidence chain tracking across agents.

**Quality gate:** "If you can't write down WHY, the reasoning is weak."

## Connection to the Other Frameworks

The Helix Engine v6 runs the frameworks, it doesn't replace them:

- **LLV** determines which agent pattern to deploy (Lines → ARCHITECT, Loops → EVOLVE, Vibes → SENSING)
- **9Q** provides the positioning question the engine analyses
- **AAA** maps the organisation's capability to the level of engine engagement appropriate

Think of it as the orchestration layer on top of the IP.
